# 中译英回复 for Gmail — 隐私政策 / Privacy Policy

最后更新 / Last updated: 2026-10-13

## 中文

「中译英回复 for Gmail」是一个 Chrome 插件，用来把你在 Gmail 回复框里写的中文翻译成英文。

**会处理哪些数据**

- 你在 Gmail 回复框里写的正文（不包括签名和引用的原邮件）。
- 如果在设置里打开了「参考客户来信」（默认打开），还会处理你正在回复的那封邮件的主题和正文，作为翻译的上下文。

**数据发到哪里**

- 只有在你点「译 英文」、按快捷键，或者发送前检查发现中文并弹出翻译窗口时，上述内容才会通过 HTTPS 发送给 DeepSeek 的 API（api.deepseek.com），用来生成译文。
- DeepSeek 如何处理这些数据，以 DeepSeek 官网公布的隐私政策为准。
- 除了 DeepSeek，插件不会把任何数据发给其他地方。

**保存在你电脑上的数据**

- 你的 DeepSeek API Key 和插件设置（语气、术语表等）只保存在你本机浏览器的插件存储（chrome.storage.local）里。API Key 只在请求 DeepSeek 时作为身份验证使用。

**开发者不会做的事**

- 不收集、不保存、不查看你的邮件内容或任何个人信息。插件没有自己的服务器，也没有任何统计、分析或广告代码。
- 不出售、不转让用户数据，也不把数据用于翻译以外的任何用途。

**如何删除数据**

在 `chrome://extensions` 里移除插件，本机保存的设置和 API Key 会一起删除。

**联系方式**

请通过 Chrome 应用商店页面上显示的开发者联系方式联系。

## English

"中译英回复 for Gmail" is a Chrome extension that translates the Chinese you write in a Gmail reply box into English.

**Data processed**

- The text you write in the Gmail compose box (excluding your signature and the quoted original email).
- If "Use the incoming email as context" is enabled in settings (on by default), the subject and body of the email you are replying to, used as translation context.

**Where data is sent**

- Only when you click the translate button, press the shortcut, or when the pre-send check finds Chinese and opens the translation dialog, the content above is sent over HTTPS to the DeepSeek API (api.deepseek.com) to produce the translation.
- DeepSeek's handling of that data is governed by DeepSeek's own privacy policy.
- No data is sent anywhere else.

**Data stored on your device**

- Your DeepSeek API key and extension settings (tone, glossary, etc.) are stored only in your browser's extension storage (chrome.storage.local). The API key is used only to authenticate requests to DeepSeek.

**What the developer does not do**

- The developer does not collect, store or view your emails or any personal information. The extension has no server of its own and contains no analytics, tracking or advertising code.
- User data is not sold or transferred, and is not used for any purpose other than translation.

**Deleting data**

Removing the extension at `chrome://extensions` deletes the locally stored settings and API key.

**Contact**

Please use the developer contact shown on the Chrome Web Store listing.
